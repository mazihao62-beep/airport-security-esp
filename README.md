## 🐛 v12.5 核心修复：全部NPC判为坏人的Bug

**根因：** `classifyNPC` 函数中路径检查 `pl:find("npc")` 匹配所有路径含"npc"的角色。由于所有NPC都在 `NPCWorkspace/NPCTemplate` 下，全部命中 → 全部显示为坏人 ❌

**修复：** 彻底移除 `"npc"` 路径坏人关键词（太宽泛），改用精确词匹配。同时加强名字匹配、属性检测、Humanoid状态检查。

## ✨ 功能

- 👁 **透视高亮** — Highlight穿墙显示所有NPC
- 🔍 **智能分类** — 7层检测：属性→名字→颜色→父级→工具→路径→状态
- 🏷 **头顶标签** — 显示类型/距离/血量信息
- 🔧 **自定义快捷键** — 透视开关、仅坏人模式
- 💾 **配置保存** — 自动保存/读取所有设置
- 🎨 **主题系统** — 16种内置主题一键切换
- ✨ **粒子背景** — 窗口内浮动粒子，Clips裁剪
- 🧹 **即时清理** — 启动时自动清除上次残留
- 📊 **调试日志** — 每帧显示NPC属性信息

## ⌨️ 默认快捷键

| 按键 | 功能 |
|------|------|
| `RightShift` | 打开/关闭窗口 |
| 无 | 透视开关（需在功能设置绑定） |
| 无 | 仅坏人模式（需在功能设置绑定） |

## 🎮 使用方法

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/mazihao62-beep/airport-security-esp/main/airport_esp.lua"))()
```

加载后：
1. ✅ 弹出确认窗 → 点击「确认加载」
2. ⌨️ 按 `RightShift` 打开菜单
3. 👁 去「主控面板」开启透视开关
4. 🔑 去「功能设置」绑定快捷键
5. 📊 去「信息统计」查看NPC分布和调试日志
