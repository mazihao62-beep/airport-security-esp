# 机场安全透视脚本 ✈️

**作者: b站英吉利超入_**

用于 Roblox 机场安全游戏的透视（ESP）脚本，自动识别好人与坏人并高亮标记。

---

## 🚀 使用方式

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/mazihao62-beep/airport-security-esp/main/airport_esp.lua"))()
```

---

## 🎮 首次使用流程

1. 执行脚本 → Popup弹窗显示功能说明
2. 点击 **「确认加载」**
3. 按 **RightShift** 打开菜单（或手机点悬浮按钮 👁）
4. 在「UI设置」中绑定窗口快捷键
5. 在「功能设置」中绑定透视快捷键
6. 在「主控面板」开启透视开关

---

| 操作 | 说明 |

| 操作 | 说明 |

## ✨ 功能

| 功能 | 默认 | 说明 |
|------|:---:|------|
| 👁 透视开关 | ❌ 关 | NPC高亮 + 头顶标签 |
| 👤 仅显示坏人 | ❌ 关 | 只显示坏人 |
| 📏 显示距离 | ❌ 关 | 头顶显示距离 |
| ❤️ 显示血量 | ❌ 关 | 头顶显示血量 |
| 🎚 探测距离 | 500m | 最大探测范围 |

---

## 🏷 NPC识别

| 方法 | 优先级 |
|------|:-----:|
| `NPCType` 属性 (NPCSetup.lua) | 🥇 |
| 中文名 (警察/保安/警卫...) | 🥈 |
| 英文名 (Police/Guard/Agent...) | 🥉 |
| 路径 (AgentTemplate/NPCTemplate) | 4️⃣ |
| TeamColor (蓝绿=好人, 红棕=坏人) | 5️⃣ |
