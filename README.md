# 机场安全透视脚本 🔍

**作者: b站英吉利超入_**

用于 Roblox 机场安全游戏的透视（ESP）脚本，自动识别好人与坏人并高亮标记。

---

## ⚠️ v6.4 重要变更

**所有功能默认关闭！** 加载后需要手动开启透视开关。

---

## 🎮 使用方式

复制以下代码到你的执行器：

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/mazihao62-beep/airport-security-esp/main/airport_esp.lua"))()
```

---

## 🖥 PC 操作

| 操作 | 说明 |
|------|------|
| **RightShift** | 打开/关闭菜单（可自定义） |
| 菜单 → 主控面板 | 开启透视、调整设置 |
| 菜单 → 功能设置 | 自定义快捷键 |

## 📱 手机操作

| 操作 | 说明 |
|------|------|
| 点击 **👁 绿色悬浮按钮** | 打开/关闭菜单 |
| 菜单 → 主控面板 | 开启透视、调整设置 |

---

## ✨ 功能列表

| 功能 | 默认状态 | 说明 |
|------|:-------:|------|
| 👁 透视开关 | ❌ 关闭 | 开启后显示NPC高亮和头顶标签 |
| 👤 仅显示坏人 | ❌ 关闭 | 只标记坏人，好人隐藏 |
| 📏 显示距离 | ❌ 关闭 | 头顶标签显示距离 |
| ❤️ 显示血量 | ❌ 关闭 | 头顶标签显示血量 |
| 🎚 探测距离 | 500m | 最大探测范围 |
| 🔑 快捷键自定义 | 可设置 | 透视/仅坏人/窗口 快捷键 |

---

## 👁 NPC识别机制

| 识别方式 | 说明 |
|---------|------|
| `NPCType` 属性 | 源码 `NPCSetup.lua` 设置，最可靠 |
| 中文名称匹配 | 警察/保安/警卫 → 🟢 好人 |
| 英文名称匹配 | Police/Guard/Agent → 🟢 好人 |
| 路径检测 | AgentTemplate → 🟢 好人 |
| TeamColor | 蓝/绿/白 → 🟢 好人 |
| 无法判断 | ⛔ 跳过不显示 |
